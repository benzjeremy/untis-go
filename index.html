WebUntis auf deinem Desktop.
Schnell. Präzise. Respektvoll.

untis-go ist der freie, quelloffene Desktop-Client für WebUntis auf Linux und Windows. Mit Microsoft 365 & OneDrive Cloud-Synchronisierung, Einrichtungs-Wizard, 1-Klick Gast-Login, synchronem Einzelstunden-Zeitraster, Live-Countdown-Timer, lokal verschlüsseltem SQLite-Cache und nativer 60 FPS Performance.

Download für Linux untis-go-v2.1.0-linux.tar.gz (x86_64)
Download für Windows untis-go-v2.1.0-windows.zip (x86_64)
Go Entwickler: go install github.com/benzjeremy/untis-go@v2.1.0

Entwickelt für den echten Schulalltag

Keine überladenen Browser-Tabs mehr. Alle Stundenpläne, Notizen und Vertretungen auf den Punkt gebracht.

Synchrone Stundenplan-Matrix

Wiederhergestellte Zeitspalte (Std. / Zeit) mit 1. Stunde, 2. Stunde usw. Mehrstündige Blockstunden werden transparent auf jede einzelne Schulstunde aufgeteilt.

Live-Countdown mit Sekunden

Sekundengenaue Live-Anzeige bis zur nächsten Pause, Stunde oder Schultag. Immer im Blick: „Jetzt: Fach · Noch MM:SS bis Pause“.

Eigene Fachnamen & Filter

Eigene Wunsch-Aliasse für Fächer dauerhaft sichern (z.B. „Fachpraxis IT · FB02“). Integrierter Profanity-Filter schützt vor anstößigen Begriffen.

Höchste Datensicherheit

Passwörter sind mit gerätegebundener AES-256-GCM Verschlüsselung in SQLite gesichert. Dynamische Server-Ports und 32-Zeichen Session-Token.

Integrierter Auto-Updater

Prüft neue Releases direkt über die GitHub API. Ein Klick lädt das Update atomar herunter und startet die Anwendung nahtlos neu.

Ausgezeichnet in Awesome Go

Offiziell gelistet in der weltweit führenden Sammlung kuratierter Go-Software (#6660) unter Other Software.

Microsoft 365 & OneDrive Cloud-Sync

Pflicht-Anbindung für Schüler- und persönliche Microsoft-Accounts. Automatisches Cloud-Backup deiner Stundenpläne, Profile und Hausaufgaben direkt in OneDrive.

Schnelle Installation

Installiere die Standalone-Binärdatei oder nutze die Go Toolchain.

Linux (x86_64)

Lade das Tarball herunter, entpacke es und starte die Binärdatei direkt:

tar -xzf untis-go-v2.1.0-linux.tar.gz
chmod +x untis-go
./untis-go
Linux Tarball herunterladen

Windows (x86_64)

Entpacke die ZIP-Datei an einem beliebigen Ort und führe die Exe-Datei aus:

1. untis-go-v2.1.0-windows.zip entpacken
2. untis-go.exe doppelt anklicken
3. Sofort betriebsbereit (Standalone)
Windows ZIP herunterladen
